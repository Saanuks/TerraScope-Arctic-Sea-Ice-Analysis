# TERRASCOPE
## Earth System Trend Detective

TerraScope is a scientific data analysis
application investigating Arctic September
sea-ice changes using satellite observations.

## Features
- Arctic sea-ice trend analysis
- Historical data visualization
- Year comparison
- Statistical analysis
- Interactive data explorer
- CSV downloads
- Climate insights

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- SciPy
- Plotly

## Data Source
NSIDC Sea Ice Index Version 4.0

https://nsidc.org/data/g02135/versions/4
